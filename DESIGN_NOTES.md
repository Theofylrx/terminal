# Alpaca Markets Design Analysis

## Key Design Elements from Alpaca.markets

### Color Palette
- **Background**: Clean white/light gray (#F7F9FB, #FFFFFF)
- **Primary**: Blue (#2962FF, #1E88E5)
- **Success**: Green (#00C853, #4CAF50)
- **Danger**: Red (#D32F2F, #F44336)
- **Text**: Dark gray (#212121, #424242)
- **Borders**: Light gray (#E0E0E0, #F5F5F5)

### Typography
- **Headers**: Inter/SF Pro, 24-32px, bold
- **Body**: 14-16px, regular
- **Labels**: 12px, medium, uppercase tracking

### Components
1. **Clean Data Tables**
   - Minimal borders, subtle hover states
   - Clear column headers with sorting
   - Action buttons on row hover
   - Zebra striping optional

2. **Dashboard Cards**
   - White background with subtle shadow
   - Clear hierarchy: metric > value > change
   - Icon + color for quick identification
   - Compact padding

3. **Navigation**
   - Left sidebar with icons + labels
   - Active state: blue background + white text
   - Clean, spacious layout

4. **Trading Interface**
   - Buy/Sell prominent buttons
   - Clear form layout
   - Real-time price display
   - Order preview before submit

5. **Status Indicators**
   - Green dot for active/connected
   - Red dot for inactive
   - Badge styles for order status

## Our Adaptation for Dark Theme

Since our app uses dark theme, we'll adapt:
- Background: #0F172A (slate-950)
- Cards: #1E293B (slate-800) with subtle borders
- Primary: #3B82F6 (blue-500)
- Success: #10B981 (emerald-500)
- Danger: #EF4444 (red-500)
- Text: #F1F5F9 (slate-100)

Keep Alpaca's principles:
- Clean, minimal design
- Clear data hierarchy
- Professional spacing
- Subtle interactions
- Focus on usability
